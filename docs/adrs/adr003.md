# Microsoft Agent Framework for workflow state and HITL

## Status

Accepted

## Context

HITL must pause, persist, and resume when a reviewer publishes `IntakeDecision`. LangGraph also does interrupt/checkpoint. Running both would split the story.

## Decision

Use **Microsoft Agent Framework** workflows (`WorkflowBuilder`, `FileCheckpointStorage`, `ctx.request_info()` / `@response_handler`). Do not use LangGraph.

## Consequences

Graph, pending requests, and resume live in one runtime. Azure Document Intelligence and Service Bus stay coherent on the deployment map. Checkpoints are files here; Cosmos is a later swap, not this delivery.
