# Filesystem inbox as the object-store contract

## Status

Accepted

## Context

Production would use blob storage (S3 or Azure Blob). This submission has no cloud account and must stay runnable on Windows.

## Decision

Use a local directory tree as the object-store contract:

`input` → `pending` → `in_analysis` → `completed` or `needs_human`.

Same folder names and file contract would apply on a blob prefix.

## Consequences

`pathlib` is enough. Reviewers can inspect fixtures. Runtime moves and checkpoints stay gitignored so local runs do not dirty the repo.
