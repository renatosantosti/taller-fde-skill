# LiteLLM as the only model adapter

## Status

Accepted

## Context

The demo needs a live LLM without locking the assignment to one vendor. MAF can host chat clients; that would couple provider choice to the orchestrator.

## Decision

**LiteLLM** is the only model call (`litellm.completion`). MAF orchestrates; it does not choose the provider. `LLM_MODEL` and provider keys live in `.env`.

## Consequences

Switching `gpt-4o-mini` to `anthropic/claude-…` is an env change. Timeouts, empty content, rate limits, and content filters map to typed errors, then HITL — not a crash. Clone-without-key still runs `--assemble-only`.
