# Tests never call a live LLM

## Status

Accepted

## Context

The synthesize step uses LiteLLM against a real provider in demos. CI and local `pytest` must not require keys or spend tokens. MAF is in-process and does not need a cloud namespace.

## Decision

- **Unit tests** isolate each `src/` module. LiteLLM `completion` is mocked. `load_dotenv` and `run_lead` / `resume_lead` are mocked at the CLI boundary.
- **Integration tests** run the MAF workflow in-process with a file bus and temp inbox. `src.workflow.call_llm` is mocked. No Azure Service Bus, Document Intelligence, or live model.
- Measure coverage with `pytest --cov=src`. Target at least 90% of `src/`.

## Consequences

Fail-closed paths (timeout, schema, policy, thin dossier, leftover binary) are proven without a vendor. A full demo still needs `LLM_MODEL` and a provider key in `.env`.
