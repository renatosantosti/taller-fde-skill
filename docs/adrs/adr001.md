# Start at pending; extraction is out of scope

## Status

Accepted

## Context

Leads arrive with a message and many files (PDF, images). Extracting text, tables, and image descriptions could use Tesseract or Azure AI Document Intelligence. Implementing OCR in this assignment would hide FDE judgment behind an extraction platform.

## Decision

Raw files land in `inbox/input/`. A separate document service normalizes them to `.md` / `.txt` and moves the folder to `inbox/pending/`. **This repository does not implement extraction.** The intake workflow starts at pending.

## Consequences

The map still names the extractor (criterion #2). Code only reads `.txt`/`.md`. A leftover binary in pending means the extractor did not finish and must go to HITL, not a local OCR attempt.
