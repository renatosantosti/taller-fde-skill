# Closed-loop HITL; never auto-message the lead

## Status

Accepted

## Context

A folder named `needs_human` without a way back is a dead end, not a loop. Auto-emailing the lead from a model output is an open fail and a commercial risk.

## Decision

On HITL: checkpoint, `ctx.request_info()`, publish `IntakeNeedsReview`, write `intake.json` + `hitl.md`. The reviewer (or CLI simulating them) publishes `IntakeDecision` (`bid` | `decline` | `request_call`). Resume applies the decision and completes. **The workflow never sends mail or chat to the lead.**

## Consequences

Communication is internal (worker ↔ Taller reviewer) via the bus. Pricing and bid submission stay with the human. The CLI `resume` command is the demo stand-in for a reviewer UI.
