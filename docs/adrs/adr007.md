# Fail closed to HITL

## Status

Accepted

## Context

LLM integrations fail in predictable ways. Treating those failures as “send anyway” would automate a commercial side effect.

## Decision

These conditions escalate to HITL, never to a lead-facing action: timeout, invalid schema, policy/refusal, low confidence, thin dossier, leftover non-text file in pending, more than 8 files, or more than ~20k assembled characters.

## Consequences

Typed errors in `src/errors.py` become `IntakeNeedsReview` reasons. Tests can inject schema/refusal without a live provider. Happy-path auto-complete is allowed only when fit and confidence pass.
